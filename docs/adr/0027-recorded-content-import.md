# 0027. 녹음이 끝난 실제 교재 자료로 콘텐츠를 넣는다 — 목소리 4개와 재생 속도, 레벨별 지문 수, 보충 회차

- 상태: 결정 · 날짜: 2026-11-09

## 배경
지금 DB에 들어 있는 콘텐츠는 임시 개발용 회차 하나다. 녹음이 끝나고, 녹음 결과가 지금까지의 설계(0008·0023·0025·0026)와 달랐다.

| | 설계 | 실제 자료 |
|---|---|---|
| 지문 음원 | 속도별 파일(0.8·1.0·1.2), 플레이어 속도 고정(0008) | 1.0 속도 하나. 같은 지문을 영어 목소리 4개(미국·영국 × 여·남)가 각각 처음부터 끝까지 읽은 파일 4개. 화자가 있는 대화 지문도 화자별로 나누지 않음 |
| 지문 음원 만들기 | 가져오기 스크립트가 문장 파일을 이어 붙임(0026) | 지문 전체 파일이 이미 있음. 문장별 파일도 따로 있음 |
| 회차당 지문 | 6개(0023) | 레벨마다 다름: Mint·Green 2, Blue 12, Navy 1, Black 6 |
| 권당 회차 | 24, 진도표 24행 | Black은 24 + 보충 4 = 28. 보충 회차도 수업일에 진행 |
| 단어 | 회차당 약 57개, 단어마다 나온 지문(0025) | 음원이 있는 회차 어휘 12~30개. 나온 지문 정보 없음 |
| 회차 코드 | Black = `K-B1-nn` | 자료의 회차 ID는 `L5-B1-nn`, 보충은 `L5-B1-S1~S4` |

학생은 속도 조절을 실제로 쓴다. 너무 빨라서 못 알아들을 때 느리게 듣고, 실력을 올리려고 빠르게 듣는다. 목소리 4개도 학생이 골라 듣는 용도로 만들었다.

## 측정
지문 전체 파일이 문장 파일을 이어 붙인 것인지 확인했다. 간격은 (지문 전체 길이 − 문장 길이 합) ÷ (문장 수 − 1)로 계산했다. mp3 프레임 수로 길이를 쟀다.

| 지문(문장 수) | 미국 여 | 미국 남 | 영국 여 | 영국 남 |
|---|---|---|---|---|
| 지문 1(22) | 778ms | 774ms | 782ms | 776ms |
| 지문 2(16) | 792ms | 790ms | 792ms | 792ms |

한 지문 안에서는 목소리가 달라도 간격이 거의 같다. 차이는 mp3 프레임 단위(24ms) 안이다. 지문끼리는 약 780ms와 790ms로 조금 다르다. 그래서 지문 전체 파일은 문장 파일을 일정한 간격으로 이어 붙인 것으로 본다. 간격은 고정값으로 두지 않고 지문 파일(지문 × 목소리)마다 잰다.

## 선택지

### 속도
#### A. 속도별 파일을 만든다(0008 유지)
가져오기 스크립트가 1.0 파일로 0.8·1.2 파일을 만들고, 속도마다 트랙을 따로 둔다.
- 장점: 어떤 속도로 들었는지가 트랙으로 기록되고, 속도별 완료 조건을 그대로 쓸 수 있다
- 단점: 업로드와 트랙이 세 배가 된다. 변환 도구 설치와 검증이 더 필요하다
#### B. 1.0 파일을 플레이어 재생 속도로 조절한다
- 장점: 속도 때문에 파일이 늘지 않는다. 변환 도구가 필요 없다
- 단점: 서버는 학생이 몇 배속으로 들었는지 모른다

### 목소리
#### A. 하나(미국 여자)만 올린다
- 장점: 트랙과 업로드가 가장 적다. 학생 API의 지문별 트랙 목록에 항목이 하나만 온다
- 단점: 만들어 둔 목소리 선택을 쓰지 못한다
#### B. 4개를 모두 트랙으로 올리고 학생이 고른다
- 장점: 자료를 만든 의도대로 쓴다. 목소리마다 문장 파일이 있어 문장 시각도 목소리마다 정확하다
- 단점: 트랙과 업로드가 4배다. 학생 API의 지문별 트랙 목록이 속도 대신 목소리로 바뀐다

### 문장 시각
#### A. 문장 길이 + 지문마다 잰 간격으로 계산
- 장점: 계산이 단순하고 순수 함수로 테스트할 수 있다. 목소리마다 문장 파일이 있어 근사값이 필요 없다
- 단점: 간격이 지문 안에서 일정하다는 전제에 기댄다(측정으로 확인)
#### B. 무음 구간 검출
- 장점: 이어 붙인 방식을 몰라도 쓸 수 있다
- 단점: 문장 안의 쉼도 무음으로 잡혀서 문장 수와 어긋날 수 있다. 도구가 더 필요하다

### Black 보충 회차
#### A. 진도표에 수업일로 넣는다(Black 진도표 28행)
- 장점: 실제 수업과 같다. 밀린 수업과 교사 매트릭스에 다른 회차와 똑같이 나온다
- 단점: "권마다 24행" 고정을 권의 회차 수로 바꿔야 한다
#### B. 진도표 밖 복습 자료로 둔다
- 장점: 진도표 코드를 바꾸지 않는다
- 단점: 실제 수업일과 맞지 않는다

## 결정

1. **속도는 B.** 0.8·1.2는 1.0 파일을 플레이어 재생 속도로 조절한다. 0008을 폐기한다.
   - 플레이어는 재생 속도를 0.8·1.0·1.2 중에서만 고르게 한다
   - 몇 배속으로 들었든 트랙을 다 들으면 완료다. Green 이상도 0.8배속만으로 완료될 수 있다
2. **목소리는 B.** 영어 목소리 4개(미국 여·미국 남·영국 여·영국 남)를 지문마다 트랙으로 올리고 학생이 골라 듣는다.
   - 학생 API의 지문별 트랙 목록은 속도 대신 목소리로 구분한다(트랙·길이·문장 시각은 목소리마다)
   - 완료 판정은 지문 트랙 단위 그대로다(0006·0007). 지문마다 **목소리 4개 중 아무 트랙이나 하나**를 다 들으면 그 지문을 들은 것이다. 목소리끼리 들은 구간을 합치지는 않는다
   - 레벨별 속도 목록과 완료 규칙의 속도 조건은 목소리 기준으로 바꾼다
3. **문장 시각은 A.** 문장 i의 시작은 앞 문장 길이의 합 + i × 간격(i는 0부터)이고, 끝은 시작 + 문장 i의 길이다. 간격과 문장 길이는 지문 파일(지문 × 목소리)마다 그 목소리의 파일로 잰다. 근사 시각 표시는 쓰지 않는다(항상 false).
4. **지문 수는 자료 그대로**다(1·2·6·12). 회차의 모든 지문을 들어야 완료다. 회차 제목과 지문 제목도 자료에서 가져온다.
5. **Black 보충 회차는 A.** 진도표 행 수는 권의 회차 수를 따른다(Black 28, 나머지 24). 순서는 1~6 → 보충1 → 7~12 → 보충2 → 13~18 → 보충3 → 19~24 → 보충4다. 화면에는 교재 번호(`7회`, `보충 1`)를 그대로 보인다.
6. **단어는 음원이 있는 회차 어휘**다. 단어가 나온 지문은 비워 둘 수 있게 한다.
7. **회차 코드는 지금 체계(`K-B1-nn`)를 유지한다.** 가져올 때 자료의 `L5-`를 `K-`로 바꾼다. 보충 회차 코드는 `K-B1-S1~S4`다.
8. **가져오는 방법은 두 단계**다.
   - (1) PC 스크립트가 원고와 mp3 길이로 manifest를 만들고 음원을 업로드한다
   - (2) 앱의 가져오기 명령이 manifest를 검증하고, 문장 시각을 계산하고, 회차 단위로 넣는다. 다시 실행해도 결과가 같다(멱등)
   - 청취 기록이 있는 트랙의 길이가 바뀌면 그 회차는 넣지 않고 보고한다
9. **임시 개발용 회차는 실제 자료로 덮어쓴다.**

## 근거
- 속도별 파일이 없으니 파일을 새로 만들기보다 재생 속도로 조절하는 쪽이 작고 확실하다.
- 목소리 4개는 학생이 골라 듣도록 만든 자료다. 목소리는 취향이라 특정 목소리를 필수로 둘 이유가 없어서, 아무 목소리로나 끝까지 들으면 완료로 친다.
- 문장 시각은 측정으로 전제를 확인했다. 계산은 순수 함수라 테스트하기 쉽다.
- 보충 회차는 실제로 수업일에 진행하므로, 진도표가 수업과 같아야 밀린 수업 판정이 맞는다.
- 회차 코드는 저장소와 화면 곳곳에서 쓰이는 식별자(0011)다. 자료 쪽 표기를 가져올 때 한 번 바꾸는 편이 덜 바꾼다.

## 포기한 것
- **배속 편법 차단(0008의 이유).** 서버는 재생 속도를 모른다. 플레이어 선택지를 0.8~1.2로 제한하는 것으로 대신한다.
- **속도별 완료 조건.** "Green 이상은 1.0으로 들어야 완료"를 더 이상 쓰지 않는다.
- **2차로 미룬 것.**
  - 한국어 해석 음원, 영어-한국어 번갈아 음원
  - 문장 해석과 핵심 문장 표시, 단어별 시각 강조
  - 교재 어휘책의 단어·숙어

## 재검토 조건
- 교사가 학생별 재생 속도를 보고 싶어 하면, 청취 기록에 재생 속도를 함께 보낸다.
- 지문 안에서 문장 사이 간격이 일정하지 않은 자료가 오면, 무음 검출로 문장 시각을 대조한다.
- 교사가 "한 지문을 여러 목소리로 나눠 들어도 완료"를 원하면, 목소리 트랙끼리 들은 구간을 합치는 규칙을 검토한다.
