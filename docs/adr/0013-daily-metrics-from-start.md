# 0013. 운영 지표(`daily_metric`)를 1차부터

- 상태: 결정 · 날짜: 2026-11-01

## 배경

## 선택지

- 장점: 1차 작업량 감소
- 단점: 그 전 기간의 수치는 영영 없음
### B. 일별 집계를 1차부터
- 장점: "실사용 n명, 누적 n건"의 근거가 처음부터 쌓임
- 단점: 배치 하나 추가

## 결정
B. 일별 활성 학생·세그먼트·완료 회차를 새벽 배치로 집계한다.
