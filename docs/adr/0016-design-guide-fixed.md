# 0016. 시각 디자인은 디자인 가이드로 고정, 디자인 스킬은 그 안에서

- 상태: 결정 · 날짜: 2026-11-01

## 배경
프론트 구현 시 AI 디자인 스킬을 쓸 예정이다. 와이어프레임은 구조·흐름만 정한다.

## 선택지
### A. 스킬에 화면마다 맡김
- 장점: 빠름
- 단점: 세션마다 룩이 달라짐
### B. 디자인 가이드로 기본값 고정 + 스킬은 그 안에서
- 장점: 가이드가 일관성을, 스킬이 디테일 품질을 맡음
- 단점: 가이드 작성 비용

## 결정
B. 색(레벨 색 1 + 중립)·서체(Pretendard)·간격·반경·상태 표현 문법을 디자인 가이드로 고정한다. 스킬에는 와이어프레임 + 가이드 + API 응답을 함께 넘긴다.

## 근거
스킬만 쓰면 세션마다 룩이 달라진다.

## 포기한 것
화면별 자유로운 시각 실험.

## 재검토 조건
브랜드 디자인 시스템이 정식으로 나오면 가이드의 색·서체를 그쪽에 맞춤.
