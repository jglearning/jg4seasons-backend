# 0012. 1차 범위 = 듣기 + 단어 카드, 11/11 실사용 기준

- 상태: 결정 · 날짜: 2026-11-01

## 배경
10/30 회의에서 11/11 마감이 정해졌다. 운영 측 확인(11/1): "앱은 듣기·어휘 담당", "단어는 듣기 + 카드 넘기기 수준".

## 선택지
### A. 설명된 기능 전체(받아쓰기·단어시험·문제은행·학부모·콘텐츠 관리 UI 포함)
- 장점: 한 번에 완성
- 단점: 1인 열흘로 불가능
### B. 가장 많이 쓰이는 경로(학생 듣기 → 교사 확인) + 단어 카드
- 장점: 핵심 경로를 안정적으로
- 단점: 나머지는 2차로

## 결정
B. 받아쓰기·단어시험 5칸·문제은행·학부모·콘텐츠 관리 UI는 2차. 콘텐츠 등록은 스크립트.

## 근거
1인 열흘. 가장 많이 쓰이는 경로를 안정적으로 만든다.

## 포기한 것
2차 기능 전부.

## 재검토 조건
—

## 확정(11/1)
실제 학생이 쓰는 1차. 관리자 최소 UI(반·학생·교사 관리)까지 1차에 포함.

## 변경(11/3)
문장별 빈칸 1개(0023)와 카드 학습 모드(0025)를 1차에 넣는다. 레벨별 받아쓰기·단어시험 5칸·숙제 지정·숙제 피드백은 그대로 2차.

## 변경(11/5)
문장별 빈칸(0023)은 뺀다. 회차 듣기는 지문 음원 하나 + 문장 시각으로 따라 읽기(0026).
