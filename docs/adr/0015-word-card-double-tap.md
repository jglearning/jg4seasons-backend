# 0015. 단어 카드 조작: 탭 1회 뜻, 2회 다음 단어

- 상태: 결정 · 날짜: 2026-11-01

## 배경
처음 안은 탭으로 앞뒤 토글이었다. 제안: 뜻을 본 상태에서 한 번 더 탭하면 다음 단어.

## 선택지
### A. 탭으로 앞뒤 토글
- 장점: 뜻을 가리고 다시 볼 수 있음
- 단점: 다음 단어로 가려면 버튼을 눌러야 해 손동작이 끊김
### B. 탭 → 뜻, 탭 → 다음 단어(앞면)
- 장점: 여러 장을 도는 손동작이 끊기지 않음
- 단점: 영어로 되돌리려면 "이전"을 써야 함

## 결정
B. 하단 "이전·다음" 버튼은 유지. 마지막 단어에서 2회 탭 시 `word_study.all_viewed_at` 기록.

## 근거
영어로 되돌리는 경우는 드물고 "이전"으로 대체 가능하다.

## 포기한 것
카드 뒤집어 되돌리기.

## 재검토 조건
학생들이 뜻을 가린 채 영어만 다시 보고 싶어하면 "앞면으로" 작은 버튼 추가.

## 보완(11/3)
이 조작은 단어 카드 화면에 그대로 유지. 단어 수(회차당 약 57)·자동 재생·예문은 0025.
