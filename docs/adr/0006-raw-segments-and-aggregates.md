# 0006. 청취 기록은 원본 세그먼트 보존 + 집계 테이블 분리

- 상태: 결정 · 날짜: 2026-11-01

## 배경
"건너뛰지 않고 들었는지"가 핵심 요구다. 교사 화면은 빨라야 하고, 판정 기준은 바뀔 수 있다.

## 선택지
### A. 재생 완료 이벤트만 저장
- 장점: 저장량 최소
- 단점: 건너뛰기를 감지할 수 없음
### B. 세그먼트 원본만 저장하고 조회 시 계산
- 장점: 판정 기준 변경에 유연
- 단점: 교사 매트릭스마다 수천 행 집계
### C. 원본 + 집계(track_progress, lesson_progress)
- 장점: 쓰기 시 병합 1회, 읽기는 PK 조회. 원본이 있어 기준이 바뀌어도 재집계 가능
- 단점: 쓰기 경로가 복잡해지고 저장량이 늘어남

## 결정
C. 원본은 추가만 하고, 교사 화면은 집계만 읽는다.

## 근거
A는 요구를 만족하지 못하고 B는 읽기 비용이 크다. C는 두 문제를 모두 피한다.

## 포기한 것
저장 공간과 쓰기 단순성.

## 재검토 조건
세그먼트가 연 500만 행을 넘으면 월 파티션 + 1년 이상 아카이브.
