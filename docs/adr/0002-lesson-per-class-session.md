# 0002. 학습 단위는 "수업 1회 = 회차 1개", 반 단위 진도

- 상태: 결정 · 날짜: 2026-11-01

## 배경
첫 요청은 "레벨과 시즌을 선택하면 책이 나열되고 그 주 단원을 클릭"이었다. 학생 자유 선택인지, 주 단위인지, 교사 배정인지가 불명확했다.

## 선택지
### A. 학생 자유 선택
- 장점: 구현이 단순
- 단점: 교사가 "오늘 들어야 할 것"을 통제할 수 없음
### B. 주 단위 자동
- 장점: 진도 데이터가 필요 없음
- 단점: 교재는 회차 단위로 운영되고 시험 기간에는 쉬므로 날짜 기반 자동 계산이 맞지 않음
### C. 반 단위 수업 회차 진도표
- 장점: 교재 운영 방식과 같음. 휴강·보강만 조정하면 됨
- 단점: 반마다 진도표를 생성·관리해야 함
### D. 교사가 학생별 배정
- 장점: 개별 예외 처리 가능
- 단점: 교사 작업량이 큼. 1차 요구에 없음

## 결정
C. 반 생성 시 24회 진도표를 자동 생성한다. 수업일이 지난 회차만 열린다. 교사는 휴강·보강만 조정한다.

## 근거
운영 측 확인(11/1): "매 주가 아니라 매 수업마다. 수업 내용은 이미 정해져 있다." 교재 운영도 회차 단위이고, 시험 기간에는 모듈 사이에서 쉰다.

## 포기한 것
학생별 개별 진도.

## 재검토 조건
결석생 개별 진도, 보충반 등 학생별 예외가 반복되면 수강(enrollment) 단위 오버라이드 추가.
