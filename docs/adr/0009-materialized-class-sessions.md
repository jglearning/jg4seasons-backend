# 0009. 진도표를 `class_session` 행으로 실체화

- 상태: 결정 · 날짜: 2026-11-01

## 배경
반의 수업일과 회차를 연결하는 진도표가 필요하다. 휴강·보강·순서 조정이 생긴다.

## 선택지
### A. 개강일·요일로 매번 계산
- 장점: 저장할 것이 없음
- 단점: 예외가 하나만 생겨도 계산이 복잡해짐
### B. 24행을 미리 생성
- 장점: 휴강·보강·순서 조정이 행 수정으로 끝남. "오늘 회차" 조회가 인덱스 1회
- 단점: 반마다 24행

## 결정
B.

## 근거
예외 처리가 단순하고 조회가 빠르다.
