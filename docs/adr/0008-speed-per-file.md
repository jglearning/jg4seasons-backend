# 0008. 배속은 파일 단위, 플레이어 playbackRate 고정

- 상태: 폐기(→ 0027) · 날짜: 2026-11-01

## 배경
교재 음원이 0.8/1.0/1.2배속 파일로 따로 제작된다(TTS).

## 선택지
### A. 플레이어 배속 UI 제공
- 장점: 익숙한 기능
- 단점: 2배속으로 "완료"를 찍는 편법이 가능. 어떤 속도로 들었는지 별도 기록 필요
### B. 배속 UI 없음, 속도별 파일을 트랙으로
- 장점: 어떤 속도로 들었는지가 트랙 단위로 자연히 기록됨
- 단점: 학생이 속도를 자유롭게 고를 수 없음

## 결정
B. `playbackRate=1.0` 고정, `ratechange` 감지 시 되돌린다.

## 근거
편법을 막고, 교재 설계(레벨별 속도 활동)와 일치한다.

## 포기한 것
임의 배속 재생.

## 재검토 조건
교재 설계가 바뀔 때.

## 폐기(2026-11-09)
실제 음원은 1.0 속도 하나만 있다. 0.8·1.2는 플레이어 재생 속도로 조절하고(선택지는 0.8·1.0·1.2), 완료는 몇 배속으로 들었든 트랙 단위로 판정한다(0027).
