# 0025. 수업 단어 = 지문 6개 전체 단어, 카드는 자동 재생·품사·새 예문, 카드 학습 모드

- 상태: 일부 변경(→ 0027, 0029) · 날짜: 2026-11-03

## 배경
교사 요청(11/3): 단어는 처음 자동 재생, 뜻을 볼 때 다시 들을 수 있게. 예문·예문 해석·품사 표시. 예문은 지문 문장이 아닌 새 문장. 학생들이 이미 익숙한 단어 카드 학습 앱 형식의 학습.

## 선택지
### A. 단어 카드만(넘기기)
- 장점: 구현이 작음
- 단점: 교사 요청(학습 모드)을 만족하지 못함
### B. 카드 + 학습 모드, 모드별 최고 결과만 저장
- 장점: 학생에게 익숙한 형식이라 설명이 필요 없음. 회차당 행 1개라 교사 화면 집계가 단순
- 단점: 단어별 오답 이력이 없음
### C. 카드 + 학습 모드, 단어별 시도 기록
- 장점: 약한 단어 다시 보기 가능
- 단점: 기록 행이 단어 수만큼 늘고 1차 일정에 맞지 않음

## 결정
B.
- `word`는 회차당 약 57개. 각 단어에 지문 번호(`passage_id`), 품사(`pos`), 새 예문(`example_en`)·해석(`example_ko`), 단어 음원·예문 음원 트랙.
- 단어 카드: 카드가 나오면 단어 발음 1회 자동 재생 → 탭하면 뜻·품사·예문·해석 + "단어 듣기 / 예문 듣기" 버튼 → 한 번 더 탭하면 다음(0015 유지).
- 카드 학습: 암기(알아요/몰라요, 몰라요는 뒤로) · 리콜(단어 보고 뜻 4지선다) · 스펠(뜻 보고 철자) · 목록(지문별 필터).
- 기록: `word_study`에 카드 열람 수 + 모드별 최고 결과(알아요 수, 리콜·스펠 정답 수). 단어별 기록은 1차에 하지 않는다.

## 근거
익숙한 형식이라 설명이 필요 없다. 모드별 최고 결과만 저장하면 행이 회차당 1개라 집계가 단순하다.

## 포기한 것
단어별 오답 이력(약한 단어 다시 보기). 매칭 게임·테스트 모드.

## 재검토 조건
- 교사가 "누가 어떤 단어를 몰랐는지"를 요구하면 `word_attempt` 추가.
- 단어 데이터(품사·예문·해석·음원)의 실제 포맷은 미결.

## 일부 변경(2026-11-09)
단어는 음원이 있는 회차 어휘(회차당 12~30개)이고, 단어가 나온 지문은 비워 둘 수 있다(0027). 카드·학습 모드는 그대로다.
