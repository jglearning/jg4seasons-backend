# 0014. 학생 기기는 개인 기기 전제, 공용 태블릿 모드 1차 제외

- 상태: 결정 · 날짜: 2026-11-01

## 배경
학생이 태블릿도 쓸 수 있다. 학원에 비치된 공용 태블릿이면 로그인 유지(90일)가 앞 학생 기록을 다음 학생에게 섞는다.

## 선택지
### A. 공용 기기 모드(세션 즉시 만료 + 학생 전환) 1차 포함
- 장점: 공용 기기에서도 안전
- 단점: 토큰 수명·전환 UI·입장 흐름이 모두 달라져 하루 이상 소요
### B. 개인 기기 전제, 레이아웃만 대응
- 장점: 추가 화면 없음
- 단점: 공용 기기 운영 학원은 1차에 쓸 수 없음

## 결정
B. 학생 화면은 단일 컬럼을 `max-width: 520px` 가운데 정렬로 태블릿에 대응한다.

## 근거
요구가 "공용 말고 학생 개인용"이었다.

## 포기한 것
공용 기기 운영.

## 재검토 조건
어떤 학원이 공용 태블릿 운영을 요청하면 `academy.settings.shared_device=true`로 세션 30분 만료 + 홈에 "다른 학생으로 전환" 추가.
