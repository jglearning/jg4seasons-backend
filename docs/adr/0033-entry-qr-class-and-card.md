# 0033. 입장 QR — 반 QR과 학생 카드 QR을 함께 쓴다

- 상태: 결정 · 날짜: 2026-11-12 · 보완: 0022

## 배경
학생은 처음 한 번 가입 코드(반 공용 영숫자 8자)와 개인 코드(숫자 4자리)를 직접 입력한다(0022). 초6~중3 학생이 폰으로 12자를 치는 단계라 첫 입장에서 막히기 쉽고, 가입 코드의 비슷한 글자를 헷갈린다.

입력을 줄일 재료는 이미 있다.
- 교사·관리자 반 목록 응답에 반의 가입 코드가 있다(PR #52).
- 명단을 등록하거나 개인 코드를 재발급하면 응답에 개인 코드 평문이 한 번 나오고, 그 결과로 학생 카드(가입 코드 + 개인 코드)를 인쇄한다.

0022의 입장 방식(가입 코드 + 개인 코드, 실패 잠금)은 바꾸지 않고, 코드를 손으로 치는 단계만 줄인다.

## 선택지
### A. 반 QR만
반 목록에서 `/join#c=<가입 코드>` QR을 띄우거나 링크를 반에 공유한다. 학생은 개인 코드 4자리만 입력한다.
- 장점: 새 위험 없음(가입 코드는 원래 반에 공지하는 값). 카드가 없어도 쓴다
- 단점: 첫 입장에도 4자리 입력이 남는다
### B. 학생 카드 QR만
카드에 `/join#c=<가입 코드>&p=<개인 코드>` QR을 인쇄한다. 찍으면 두 칸이 채워진다.
- 장점: 첫 입장 입력 없음
- 단점: 카드를 잃어버리거나 집에 두면 다시 12자 입력. QR 사진이 퍼지면 그 학생으로 들어갈 수 있다
### C. 둘 다
카드를 나눠 준 첫 입장은 카드 QR, 카드가 없거나 기기를 바꾸면 반 QR + 4자리.
- 장점: 첫 입장 입력 없음, 카드가 없을 때도 12자를 치지 않는다
- 단점: 프론트 화면 두 곳(반 목록, 카드 인쇄). 카드 QR의 위험은 B와 같다
### D. 1회용 입장 토큰
서버가 학생마다 한 번만 쓰는 토큰을 만들고 QR에 담는다.
- 장점: QR 사진이 퍼져도 한 번 쓰면 끝
- 단점: 토큰 발급·만료·소모 API와 저장이 새로 필요. 첫 입장에 실패하면 다시 인쇄해야 한다
### E. 교실 화면 QR + 교사 승인
교실 화면의 QR을 찍으면 교사 화면에 요청이 뜨고 교사가 승인한다.
- 장점: 코드가 없다
- 단점: 수업 중 교사 일이 늘고, 집에서 기기를 바꾸면 들어올 수 없다
### F. 소셜 로그인
- 장점: 학생이 이미 쓰는 계정
- 단점: 만 14세 미만 법정대리인 동의 절차가 필요하고 수집하는 개인정보가 늘어난다(0003에서 뺀 이유와 같음)

## 결정
C. 두 QR을 함께 쓴다. 서버 API·저장은 바뀌지 않는다.

| | 반 QR | 학생 카드 QR |
|---|---|---|
| 주소 | `/join#c=<가입 코드>` | `/join#c=<가입 코드>&p=<개인 코드>` |
| 만드는 곳 | 교사 반 목록·관리자 반 관리(가입 코드는 반 목록 응답에 있음) | 명단 등록·개인 코드 재발급 결과로 카드를 인쇄할 때 |
| 학생 입력 | 개인 코드 4자리 | 없음 |

- 코드는 주소의 `#` 뒤(fragment)에 둔다. fragment는 서버로 보내지지 않아 서버·CDN 접근 로그와 Referer에 남지 않는다.
- 입장 화면은 fragment를 읽어 칸을 채운 즉시 `history.replaceState`로 주소에서 지운다. 방문 기록·화면 공유에 코드가 남지 않게 한다.
- 카드 QR로 열어도 자동으로 로그인하지 않는다. 두 칸이 채워진 입장 화면에서 학생이 "들어가기"를 한 번 누른다. 다른 사람이 카드를 찍기만 해도 들어가지는 일을 막고, 반 이름을 확인할 기회를 준다.
- 카드 QR은 개인 코드 평문이 있는 때(발급·재발급 응답)에만 만들 수 있다. 개인 코드는 다시 볼 수 없으므로(0022) 카드를 잃어버리면 재발급하고 새 카드를 인쇄한다.
- 로그인은 기존 학생 로그인 API와 실패 잠금을 그대로 쓴다. QR로 들어온 시도도 같은 카운터로 센다.
- 가입 코드가 재발급됐거나 개인 코드가 바뀌어 맞지 않으면 기존 오류를 그대로 보여 준다. 새 오류 code는 없다.
- 첫 입장 뒤에는 홈 화면에 추가하도록 안내한다(자동 로그인 90일은 0022 그대로).

## 근거
- 첫 입장이 "카메라로 찍기 → 들어가기"로 끝나고, 카드가 없을 때도 4자리만 입력한다.
- QR에 담는 값은 이미 카드에 인쇄되는 값과 반에 공지하는 값뿐이라, 0022의 위험 판단(4자리 찍어 맞추기와 실패 잠금)은 바뀌지 않는다.
- 서버 변경이 없어 1회용 토큰(D)보다 만들고 운영할 것이 적다.

## 포기한 것
- 카드 QR 사진이 퍼지면 그 학생으로 들어갈 수 있다. 인쇄된 카드 사진이 퍼진 것과 같은 수준이고, 대응은 개인 코드 재발급이다.
- 카드를 잃어버렸을 때 같은 QR을 다시 인쇄할 수 없다. 재발급하면 기존 로그인이 끊기고 새 카드가 필요하다.
- 반 QR이나 링크가 반 밖으로 퍼지면 가입 코드가 퍼진 것과 같다. 대응은 가입 코드 재발급이고, 재발급하면 예전 QR·링크로는 들어올 수 없다.

## 재검토 조건
- 카드 QR 유출로 대신 듣기가 실제로 생기면 1회용 토큰(D)을 검토한다.
- 카드 분실 재발급이 잦아 교사 부담이 크면 개인 코드 다시 보기(0022 재검토 조건)와 함께 본다.
