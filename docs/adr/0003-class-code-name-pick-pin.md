# 0003. 입장은 반별 공용 코드 + 이름 선택 + 개인 PIN

- 상태: 폐기(→ 0022) · 날짜: 2026-11-01

## 배경
초6~중3 학생이 집 폰에서 쓴다. 아이디·비밀번호 가입은 이탈이 크고, 교사가 명단을 관리해야 한다.

## 선택지
### A. 아이디/비밀번호 가입
- 장점: 익숙한 방식
- 단점: 가입 단계 이탈, 비밀번호 분실 대응
### B. 학생별 개인 코드
- 장점: 입력 하나
- 단점: 코드만으로 학원 밖에서 찍어 맞출 여지
### C. 반별 공용 코드 + 이름 선택 + PIN
- 장점: 코드 1개를 반 단체방에 공지하면 끝. 관리가 가장 쉬움
- 단점: 공용 코드라 이름만 고르면 타인 계정 진입이 가능하므로 PIN이 필요
### D. 소셜 로그인
- 장점: 비밀번호 관리 없음
- 단점: 14세 미만 동의 절차, 명단 연결 단계 추가, 개인정보 수집 증가

## 결정
C. 교사가 명단 등록 → 학생은 코드 입력 → 이름 선택 → PIN 4자리 설정.

## 근거
PIN은 "선택한 학생" 안에서만 비교되므로 4자리로 충분하다. 소셜 로그인은 1차에 부적합하다.

## 포기한 것
4자리 PIN은 반 친구가 어깨너머로 볼 수 있다. 보호 대상이 학습 기록 조회·대리 청취뿐이고 5회 실패 잠금으로 무차별 시도는 막히므로 받아들였다.

## 재검토 조건
학부모 열람 기능 도입 시 학부모용 소셜 로그인 추가(0005에서 인증 수단 분리).

## 폐기 이유(2026-11-03)
교사 피드백: 학생이 명단에서 자기 이름을 찾는 과정이 길다. 로그인하면 바로 자기 홈으로 가야 한다. → 0022.
