# 0040. 프리토킹 학생 허용을 구독과 별도 표로 분리, 꺼진 학생은 숨김

- 상태: 결정 · 날짜: 2026-11-28

## 배경
- 실사용은 프리토킹을 전부 닫은 채 시작. 운영자가 학생마다 켜는 방식으로 열기로 함. 결제는 그다음
- 지금 켜고 끄는 단위는 학원 하나

| 값 | 위치 | 꺼지면 |
|---|---|---|
| `features.talk` | `academy.settings` | 404 `FEATURE_DISABLED`, 진입점 숨김 |
| `features.talkEntitled` | `academy.settings` | 설정 조회 `entitled: false`, 세션 생성 403 `SUBSCRIPTION_REQUIRED`, 잠금 화면 |

- 기획: 3단계에서 학생·학원 단위 권한 표로 교체(권한 표 하나에 구독까지)
- 구독 주체(학원·개인), 기간, 해지 규칙은 미정

## 선택지
### A. talk 모듈에 학생 허용 표(켜짐·꺼짐만), 구독은 나중에 따로
- 장점
  - 구독 규칙 없이 바로 가능
  - 꺼짐(숨김)과 구독 없음(잠금)이 다른 값이라 화면 규칙 유지
- 단점
  - 구독이 붙으면 학생 확인이 두 번(허용 → 구독)
### B. 권한 표 하나를 지금 생성(출처 `manual`·`payment`, 시작·끝 시각)
- 장점
  - 결제가 붙을 때 줄만 추가
- 단점
  - 미정인 구독 주체·기간을 지금 정해야 함
  - 운영자 꺼짐(숨김)과 기간 만료(잠금)를 한 표에서 구분할 규칙 추가
### C. `user` 표에 `talk_enabled` 칸 추가
- 장점
  - 표 추가 없음
- 단점
  - auth 모듈에 talk 개념 유입
  - 학생 설정(`user_setting`)은 학생 본인이 `PATCH`로 바꾸는 칸이라 같은 자리에 둘 수 없음

## 결정
A.

| 항목 | 값 |
|---|---|
| 표 | `talk_student_access`: `academy_id` · `student_id`(고유) · `enabled` · `changed_by` · `created_at` · `updated_at` |
| 기본값 | 행 없음 = 꺼짐. 새 학생 꺼짐, 기존 데이터 채우기 없음 |
| 확인 순서(새 대화: 설정 조회·세션 생성) | 학원 활성(401) → `features.talk`(404) → 학생 허용(404 `FEATURE_DISABLED`) → `entitled`(세션 생성만 403) |
| 이미 시작한 세션(종료·조회) | 학원 활성만. 대화 중에 학원 기능·학생 허용이 꺼져도 저장·조회(음성은 브라우저와 모델이 직접 연결 — 종료를 막아도 대화는 멈추지 않고 기록만 잃음) |
| 학원 스위치 | 유지. 학원 단위 비상 차단(학생 값과 AND) |
| 바꾸는 사람 | 운영자(`SUPERADMIN`)만. `GET`·`PUT /api/v1/system/academies/{id}/talk/students` |
| 여러 명 변경 | 한 번에 1~500명. 그 학원 재원생이 아닌 id가 하나라도 있으면 404, 변경 없음 |
| 감사 기록 | `TALK_ACCESS_SET`: 한 건에 학원 id·학생 수·`enabled` |

## 근거
- 꺼진 학생은 기능이 없는 것(숨김), 구독 없는 학생은 기능이 잠긴 것(잠금). 화면과 오류 code가 이미 다름
- 결제가 붙어도 운영자가 특정 학생을 막거나 열어 줄 스위치는 계속 필요. 버릴 표가 아님
- 구독 규칙 없이 실사용 첫 주 안에 가능

## 포기한 것
- 표 하나로 권한 전체를 보는 단순함. 구독이 붙으면 학생 확인이 두 단계
- 기간 지정. 켜 둔 학생은 운영자가 끌 때까지 켜짐
- 퇴원 때 정리. 퇴원생 행은 그대로 남아 재입학하면 이전 값 유지(목록은 재원생만, 퇴원생은 로그인 불가)
- 반 단위 일괄 켜기. 여러 명 `PUT`으로 대신
- 대화 중 즉시 차단. 끄면 다음 대화부터 막힘, 진행 중 대화는 브라우저 타이머(180초)까지

## 재검토 조건
- 구독(결제) 규칙을 정할 때: 구독 표를 이 표 위에 둘지, 합칠지
- 운영자 말고 학원 관리자가 켜고 끄게 할 때(역할 확장)
- 학원당 학생이 수천 명이 되어 목록에 페이지 나눔이 필요할 때
