# 0011. 회차 코드(`L2-B1-05`)를 자연키·외부 ID로

- 상태: 결정 · 날짜: 2026-11-01

## 배경
교재·음원 파일명·문제은행·회차 마스터가 모두 회차 코드를 쓴다.

## 선택지
### A. 숫자 id만 외부에 노출
- 장점: 일반적인 방식
- 단점: 운영자가 보는 번호와 시스템 식별자가 달라 매번 대응표가 필요
### B. 회차 코드를 UNIQUE 자연키로 외부 노출, 내부 FK는 숫자 id
- 장점: 소통 비용 없음. 음원 동기화 스크립트가 파일명만으로 회차를 찾음
- 단점: 코드 체계가 바뀌면 외부 식별자도 바뀜

## 결정
B. `lesson.code` UNIQUE, API 경로와 응답에 코드 노출. 내부 FK는 숫자 id.

## 근거
운영자가 보는 번호와 시스템 식별자가 같아야 소통 비용이 없다.

## 포기한 것
코드 체계 변경에 대한 독립성.

## 재검토 조건
없음.
