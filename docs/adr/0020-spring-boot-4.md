# 0020. Spring Boot 4.x (Java 21)

- 상태: 결정 · 날짜: 2026-11-02

## 배경
설계 문서는 Spring Boot 3을 가정했다. 3.5의 오픈소스 지원은 2026-06-30에 종료됐고, 현재 기본은 4.x다.

## 선택지
### A. 3.5
- 장점: 예제·자료가 많음
- 단점: 지원이 끝난 버전
### B. 4.x
- 장점: 지원 중인 버전. 새 프로젝트라 마이그레이션 비용 없음
- 단점: 스타터가 모듈 단위로 나뉘어(예: `spring-boot-starter-flyway`, `-webmvc`) 의존성 이름이 다를 수 있음

## 결정
B. Initializr 기본 안정 버전(스냅숏·마일스톤 제외), Java 21. 생성 시점 4.1.2.

## 근거
지원이 끝난 버전으로 새 프로젝트를 시작할 이유가 없다.

## 포기한 것
3.x 기준 예제·블로그 자료를 그대로 쓰기. 4.x API는 최신 문서로 확인한다.

## 재검토 조건
4.0 지원 종료(2026-12-31) 전에 최신 4.x 마이너 유지.
